# Проект для картографического сервиса YouMap

## Постановка задачи

Бизнесу важно оперативно реагировать на негативные отзывы.
Необходимо разработать модель классификации отзывов. Выбрать подход к предсказанию (метрики, признаки, модель) и обосновать его.

**Главные вопросы:**
- Как представление данных влияет на качество нейросетевой модели?
- Какой вариант лучше помогает находить негативные отзывы?


## Данные

ССылка на датасет:
- https://code.s3.yandex.net/datasets/ds_s26_geo_reviews


Таргет - бинарный признак:
- Отзыв негативный с оценкой 1-2:`target = 1`, 
- отзыв позитивный с оценкой 3-5: `target = 0`

## Детали

Необходимо реализовать и сравнить 2 подхода:
1. Числовые признаки текста + MLP
2. Индексы токенов + эмбеддинги + mean pooling + MLP


### Метрики

Основная:
- PR-AUC, рассчитанная по вероятностям

Дополнительные:
- ROC-AUC — демонстрирует общее качество классификации .
- Precision — показывает, какая доля найденных негативных отзывов действительно относится к классу 1 .
- Recall — показывает, какую долю всех негативных отзывов удалось найти.
- F1 — характеризует баланс precision и recall.
